Como executar:

npm install
npm run dev

Framework escolhido: React + Tailwind CSS

Escolhi esse framework por já estar habituado e ter prática com esse stack. A Junção desses dois elementos permite criar códigos HTML, CSS, JAVASCRIPT em um único arquivo tornando o desenvolvimento e compreensão muito mais práticos. Além de ser uma stack extremamente popular na atualidade.

IHC (Interação Humano-Computador)

Os campos e botões deixam claro que podem ser preenchidos ou clicados, a aplicação avisa quando um item é adicionado, atualizado ou removido, e não deixa adicionar item com nome vazio. Remover um item pede confirmação antes de excluir. O React mantém a tela sempre como um reflexo direto do estado da lista, então ela nunca fica desatualizada ou inconsistente, e o Tailwind permitiu repetir as mesmas cores e espaçamentos em todos os elementos com facilidade.
